# Битовый массив: размер, вариант 2

Состояние блоков файловой системы описывается битовым массивом: на каждый блок ФС приходится ровно один бит. Объём файловой системы — `512 Гб`. Размер блока `N = 1024` байт. Сколько места занимает битовый массив в **байтах**?

В этом условии `Гб` трактуется как GiB: `1 GiB = 2^30` байт; это двоичная единица объёма, не гигабиты. Массив описывает все блоки ФС, в том числе содержащие сам массив; эти блоки уже входят в указанный общий объём, а не прибавляются к нему. Считайте только сам битовый массив, без заголовков и других метаданных. Для хранения неполного байта нужен целый байт; при ответе в блоках неполный блок также округляется вверх.

Источник: «Задачи.md», «Битов много не бывает», вариант 2.

---

# решение

Число описываемых блоков: `B = 512 · 2^30 / 1024 = 2^29 = 536870912`.

На каждый из `B` блоков нужен один бит, поэтому длина массива в битах равна `536870912`. В байтах:

`S = ceil(B / 8) = ceil(536870912 / 8) = 67108864` байт.

Если размещать массив в блоках ФС, он занимает

`A = ceil(S / N) = ceil(67108864 / 1024) = 65536` блоков.

Оба округления в данном варианте точные, без остатка. Запрошенная величина: **67108864 байт**. Вычитать блоки самого массива из `B` нельзя: они тоже описываются битами и уже входят в размер ФС.
