# Два канала: вариант B

Источник: `Test_20251109.md`, задание №6, вариант B.

Что будет выведено на экран? Если возможны несколько вариантов, приведите все. Предполагается, что обращение к функции вывода на экран выполняется атомарно и без буферизации. Все системные вызовы выполняются успешно. Подключение заголовочных файлов опущено. Под успешным чтением одного байта понимается получение этого байта; пустой канал при открытых концах записи блокирует чтение. Процессы, готовые к исполнению, не остаются навсегда без процессорного времени.

```c
int main() {
  char c = 'x';
  int fd[2], fd2[2];
  pipe(fd);
  pipe(fd2);

  if(fork() == 0) {
    read(fd[0], &c, 1);
    putchar('d');
    read(fd2[0], &c, 1);
    putchar('b');
    exit(0);
  }

  putchar('a');
  write(fd[1], &c, 1);
  putchar('c');
  write(fd2[1], &c, 1);
  wait(NULL);
  putchar('f');
  return 0;
}
```

---
# решение

Все возможные строки stdout (без завершающего перевода строки):
acdbf
adcbf

Полный частичный порядок: a<c, a<d, c<b, d<b, b<f. Первая запись родителя выполняется после a и разблокирует первое чтение ребёнка, поэтому a<d. Вторая запись выполняется после c и разблокирует второе чтение ребёнка, поэтому c<b. Порядок программы ребёнка даёт d<b. Родитель ждёт завершения ребёнка, следовательно, f идёт после b и последним.

Между c и d зависимости нет: после первой записи планировщик может продолжить родителя либо передать управление ребёнку. Это ровно два перечисленных линейных продолжения частичного порядка. x передаётся по каналам, но на экран не выводится. Оба чтения в конце концов получают байт, вечной блокировки нет.
