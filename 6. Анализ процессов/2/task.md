# Выхода нет

Источники: `Задачи.md`, «Выхода нет»; `Test_20251109.md`, задание №4, вариант C — та же программа. Соответствие обозначений: P1=A, P2=B, P3=D, P4=C.

Начальный процесс P1 создаёт P2 и P3; P2 создаёт P4:

```text
P1
├── P2
│   └── P4
└── P3
```

Перечислите все возможные выводы. Считайте каждый вызов `printf` атомарным и небуферизованным: одна строка не перемешивается с другой. Аргументы вычисляются до печати; между чтением PID родителя и самой печатью процесс может быть вытеснен. Все `fork` успешны. PID обозначены символами, а не конкретными числами. `R` — PID фактического усыновителя осиротевшего процесса (не обязательно 1); после усыновления он остаётся жив. Чужие процессы не создают и не завершают детей рассматриваемых процессов. Заголовки стандартных библиотек подразумеваются.

```c
int main(int argc, char **argv) {
    if (fork() == 0) {
        printf("%d %d \n", getppid(), getpid());
    }
    if (fork() == 0) {
        printf("%d \n", getpid());
        exit(0);
    }
    return 0;
}
```

---
# решение

Всего 6 выводов:

```text
P1 P2
P3
P4
```
```text
P1 P2
P4
P3
```
```text
P3
P1 P2
P4
```
```text
R P2
P3
P4
```
```text
R P2
P4
P3
```
```text
P3
R P2
P4
```

В P2 после первой печати нет `exit`: он продолжает программу и создаёт P4. Поэтому строка P2 всегда раньше строки P4. Строка P3 относительно них свободна. P1 может завершиться до чтения своего PID в качестве родителя P2; оба значения P1 и R совместимы со всеми тремя порядками. Для варианта C обозначения заменяются по указанному соответствию, а не по порядку букв алфавита.
