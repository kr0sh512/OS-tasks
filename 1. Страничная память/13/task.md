# Максимальный размер прямой и инвертированной таблиц страниц

Виртуальное адресное пространство процесса — 2 Гбайт, физическая память — 512 Мбайт, размер страницы — 8 Кбайт.

1. Сколько максимально строк может содержать обычная таблица страниц процесса?
2. Сколько строк содержит инвертированная таблица страниц операционной системы для всей физической памяти?

Примите двоичные единицы: `1 Кбайт = 2^10` байт, `1 Мбайт = 2^20` байт, `1 Гбайт = 2^30` байт. Обычная таблица имеет одну строку на виртуальную страницу процесса, включая страницы, отсутствующие сейчас в ОЗУ; инвертированная — одну строку на физический кадр. Рассматривается вся указанная физическая память без вычета служебных/зарезервированных областей. Размер каждой строки в байтах не задан и не требуется.

Источник: `Test_20251109.md`, задание №5, вариант C.

---

# решение

Виртуальное пространство имеет объём `2 · 2^30 = 2^31` байт. Размер страницы — `8 · 2^10 = 2^13` байт. Число виртуальных страниц процесса:

```text
N_virtual = 2^31 / 2^13 = 2^18 = 262144.
```

Следовательно, обычная таблица процесса может содержать максимально **262144 строки**. Наличие только 512 Мбайт физической памяти не уменьшает число виртуальных страниц: часть из них может не находиться в ОЗУ.

Физическая память имеет объём `512 · 2^20 = 2^29` байт. Число физических кадров:

```text
N_frames = 2^29 / 2^13 = 2^16 = 65536.
```

Инвертированная таблица ОС содержит **65536 строк**, по одной на кадр всей физической памяти, а не по одной на виртуальную страницу каждого процесса. Размеры таблиц в байтах без размера строк определить нельзя.
