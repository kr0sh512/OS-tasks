# Прямая таблица страниц: 32 бита и страницы по 4096 байтов

В компьютере используются 32-разрядные виртуальные и физические **байтовые** адреса типа `unsigned`. Размер страницы равен 4096 байтам. Реализуйте преобразование виртуального адреса в физический через прямую таблицу страниц, сохранив два варианта представления записи из исходных схем.

1. **Отдельные поля.** Запись имеет тип `record`, объявленный как `typedef struct record { unsigned PP; unsigned char p; } record;`. В младших 20 битах `PP` находится номер физической страницы, остальные биты `PP` равны нулю. `p = 1` означает присутствие страницы, `p = 0` — отсутствие. Функция:

   ```c
   unsigned VA_to_PA(unsigned VA, const record *table);
   ```

   При отсутствии страницы процесс отправляет **самому себе** сигнал `SIGUSR2`, затем, если обработчик сигнала вернул управление, завершает работу с кодом 1.

2. **Упакованная запись.** Таблица — массив `unsigned`; номер физической страницы занимает младшие 20 бит записи. Старший бит 31 — признак присутствия (`1` — в памяти), биты 30–20 зарезервированы и игнорируются. Функция:

   ```c
   unsigned VA_to_PA_packed(unsigned VA, const unsigned *table, pid_t pid);
   ```

   При отсутствии страницы нужно послать сигнал `SIGPL` другому, контролирующему процессу `pid`, затем завершить свой процесс вызовом `exit(No_Page)`. Константы `SIGPL` и `No_Page` задаются вне функции.

В каждом варианте вызывающая сторона предоставляет корректную таблицу из `2^20` записей для текущего процесса. Все присутствующие записи корректны; искать страницу перебором не требуется. Упакованный вариант — самостоятельный формат, а не побайтовое представление структуры `record`.

Источники: фотографии доски `photo_2026-11-18_21-11-02.jpg` и `photo_2026-11-18_21-12-13.jpg`. Полного текста условия на снимках нет. Восстановленные соглашения: точное положение и полярность бита присутствия в упакованной записи, назначение остальных флагов и описанные выше сигнатуры с различающимися именами. Схема упакованного варианта помещает `PP` в младшие 20 бит; менять её на формат «номер кадра в старших битах» нельзя. Исправления ошибок набросков разобраны в решении.

# решение

Размер страницы равен `2^12`: `VA >> 12` даёт 20-разрядный индекс виртуальной страницы, а `VA & 0xfffU` — 12-разрядное смещение. После проверки присутствия формируем `(PP << 12) | offset`.

В первом варианте `p` — отдельный байт, а не бит внутри `PP`. При `p == 0` возникает ошибка; проверка `if (rec.p)` с переходом к обработке отсутствия на первой фотографии имеет обратный смысл. Во втором варианте нельзя проверять сразу все старшие 12 бит: зарезервированные флаги не заменяют бит присутствия. Нужна отдельная маска `0x80000000U`, а для номера физической страницы — `0x000fffffU`.

`return No_Page` из второго наброска не завершает процесс и смешивает адрес с кодом ошибки, поэтому заменён на `exit(No_Page)`. В первом наброске выражение `rec.PP << OFFSET_BIT + offset` из-за приоритета операторов означает сдвиг на сумму, а не прибавление смещения; здесь используются явные скобки и побитовое ИЛИ.

Ниже оба варианта в одной единице трансляции C11/POSIX. Внешний код определяет `const int SIGPL` и `const int No_Page`; например, `SIGPL` может быть равен `SIGUSR1`. Для первого варианта вызывающая программа должна заранее установить обработчик `SIGUSR2`, возвращающий управление, либо игнорировать сигнал, если требуется наблюдать именно `exit(1)`. При стандартном действии `SIGUSR2` процесс завершится самим сигналом раньше вызова `exit` — отправка сигнала самому себе не гарантирует возврата из `kill`. Для второго варианта `pid` — положительный PID другого процесса.

```c
#define _POSIX_C_SOURCE 200809L
#include <limits.h>
#include <signal.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>

_Static_assert(UINT_MAX == 0xffffffffU, "unsigned must be 32-bit");

typedef struct record {
    unsigned PP;
    unsigned char p;
} record;

extern const int SIGPL;
extern const int No_Page;

unsigned VA_to_PA(unsigned VA, const record *table)
{
    unsigned vp = VA >> 12;
    unsigned offset = VA & 0xfffU;
    const record *entry = &table[vp];

    if (entry->p == 0) {
        (void)kill(getpid(), SIGUSR2);
        exit(1);
    }

    return (entry->PP << 12) | offset;
}

unsigned VA_to_PA_packed(unsigned VA, const unsigned *table, pid_t pid)
{
    unsigned vp = VA >> 12;
    unsigned offset = VA & 0xfffU;
    unsigned entry = table[vp];

    if ((entry & 0x80000000U) == 0U) {
        (void)kill(pid, SIGPL);
        exit(No_Page);
    }

    unsigned pp = entry & 0x000fffffU;
    return (pp << 12) | offset;
}
```

В обоих вариантах время преобразования и дополнительная память — `O(1)`. Таблица содержит `2^20` записей. Размер структуры зависит от выравнивания реализации C; нельзя автоматически считать его равным пяти байтам. Упакованная таблица содержит ровно `2^20` 32-разрядных слов, то есть 4 МиБ при восьмибитном байте.
