# Подсчёт SIGTRAP между вторым и четвёртым SIGINT

Напишите программу для POSIX-системы, которая принимает сигналы `SIGINT` и `SIGTRAP` и подсчитывает количество сигналов `SIGTRAP`, принятых после второго, но до четвёртого сигнала `SIGINT`. После седьмого `SIGINT` программа должна вывести найденное количество и завершиться успешно. В терминале нажатие `Ctrl+C` соответствует `SIGINT`; `SIGTRAP` можно отправлять командой `kill -TRAP PID`.

Правила работы:

- До второго `SIGINT` сигналы `SIGTRAP` не учитываются.
- После второго и после третьего `SIGINT` каждый принятый `SIGTRAP` увеличивает счётчик.
- С четвёртого `SIGINT` счётчик больше не меняется, но программа продолжает ждать седьмой `SIGINT`.
- На седьмой `SIGINT` программа печатает итоговое неотрицательное целое число в стандартный вывод одной строкой и завершается с кодом `0`.
- Ожидание сигналов не должно быть активным опросом. Нельзя вызывать `printf` и другие асинхронно небезопасные функции из обработчика сигнала.

Восстановленные соглашения, не уточнённые в исходном условии: программа запускается без аргументов как `./signals`; результат печатается именно при завершении; после установки маски сигналов программа сообщает свой PID в стандартный поток ошибок строкой `ready: PID`. Эта служебная строка не входит в результат.

`SIGINT` и `SIGTRAP` — обычные, не очередные сигналы: несколько одинаковых сигналов, ожидающих обработки, могут слиться в один. Поэтому условие предполагает **последовательную доставку и обработку**: отправитель посылает следующий сигнал только после приёма предыдущего программой, начиная после сообщения готовности. Если оба типа сигналов одновременно ожидают обработки, POSIX не гарантирует порядок их выбора; такой способ отправки не задаёт требуемую последовательность. Подсчёт событий, слитых операционной системой, от программы не требуется.

# решение

До начала ожидания заблокируем оба сигнала через `sigprocmask`. Затем будем получать их синхронно с помощью `sigwait`. Заблокированный сигнал, пришедший непосредственно перед `sigwait`, остаётся ожидающим: здесь нет гонки «проверить флаг — вызвать `pause`». Обработчики сигналов вообще не нужны, поэтому вывод и изменение обычных переменных выполняются в нормальном потоке управления.

Пусть `interrupts` — количество принятых `SIGINT`, а `traps` — искомый счётчик. При `SIGTRAP` увеличиваем `traps` тогда и только тогда, когда `2 <= interrupts && interrupts < 4`. При седьмом `SIGINT` печатаем результат. В решении используется `uintmax_t`; при исчерпании его диапазона программа сообщает об ошибке вместо тихого переполнения.

```c
#define _POSIX_C_SOURCE 200809L

#include <errno.h>
#include <inttypes.h>
#include <signal.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int main(void)
{
    sigset_t signals;
    sigemptyset(&signals);
    sigaddset(&signals, SIGINT);
    sigaddset(&signals, SIGTRAP);

    if (sigprocmask(SIG_BLOCK, &signals, NULL) == -1) {
        perror("sigprocmask");
        return EXIT_FAILURE;
    }

    fprintf(stderr, "ready: %jd\n", (intmax_t)getpid());
    fflush(stderr);

    unsigned int interrupts = 0;
    uintmax_t traps = 0;

    for (;;) {
        int received;
        int error = sigwait(&signals, &received);
        if (error != 0) {
            errno = error;
            perror("sigwait");
            return EXIT_FAILURE;
        }

        if (received == SIGINT) {
            ++interrupts;
            if (interrupts == 7) {
                if (printf("%" PRIuMAX "\n", traps) < 0 ||
                    fflush(stdout) == EOF) {
                    perror("stdout");
                    return EXIT_FAILURE;
                }
                return EXIT_SUCCESS;
            }
        } else if (received == SIGTRAP &&
                   interrupts >= 2 && interrupts < 4) {
            if (traps == UINTMAX_MAX) {
                fputs("SIGTRAP counter overflow\n", stderr);
                return EXIT_FAILURE;
            }
            ++traps;
        }
    }
}
```

Каждый принятый сигнал обрабатывается за `O(1)` времени, дополнительная память — `O(1)`. Обычные сигналы не превращаются в очередь от использования `sigwait`: требование последовательной отправки остаётся существенным.
