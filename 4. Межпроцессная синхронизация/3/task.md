# Очередь сообщений: выбор по типу

Источник: `Test_20251109.md`, задание № 7, вариант A.

Что будет выведено на экран в результате выполнения фрагмента? Если возможны несколько вариантов, приведите все. Вывод атомарен и не буферизуется. Все системные вызовы успешны. Заголовочные файлы опущены. `msgId` — идентификатор существующей пустой очереди сообщений System V, доступной процессу на чтение и запись и вмещающей указанные четыре сообщения. Посторонних участников нет. Обозначение `<...>` в исходнике означает опущенный окружающий код, а не синтаксис C.

```c
struct { long type; char data[1]; } msg;
/* <...>: окружающий код и корректное объявление msgId */

msg.type = 1; msg.data[0] = '1'; msgsnd(msgId, &msg, 1, 0);
msg.type = 2; msg.data[0] = '2'; msgsnd(msgId, &msg, 1, 0);
msg.type = 2; msg.data[0] = 'a'; msgsnd(msgId, &msg, 1, 0);
msg.type = 1; msg.data[0] = 'b'; msgsnd(msgId, &msg, 1, 0);

msgrcv(msgId, &msg, 1, 2, 0); putchar(msg.data[0]);
msgrcv(msgId, &msg, 1, 0, 0); putchar(msg.data[0]);
msgrcv(msgId, &msg, 1, 1, 0); putchar(msg.data[0]);
```

---
# решение

Единственная строка вывода — `21b`, без перевода строки.

После четырёх отправок очередь в порядке поступления имеет вид:

```text
(1,'1'), (2,'2'), (2,'a'), (1,'b')
```

1. `msgtyp = 2` извлекает первое сообщение **точно типа 2**, то есть `'2'`. Остаются `(1,'1'), (2,'a'), (1,'b')`.
2. `msgtyp = 0` извлекает первое сообщение независимо от типа: `'1'`. Остаются `(2,'a'), (1,'b')`.
3. `msgtyp = 1` извлекает первое сообщение точно типа 1: `'b'`. В очереди остаётся `(2,'a')`.

Для отрицательного типа действует другое правило: выбирается наименьший доступный тип, не превосходящий абсолютного значения аргумента, а внутри этого типа — первое сообщение. В данном фрагменте отрицательного аргумента нет; применять это правило к положительному `2` было бы ошибкой. `msgsz = 1` — размер полезных данных, поле `long type` в него не входит.
