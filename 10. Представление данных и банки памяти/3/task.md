# Несовместимость восьмеричного числа с 16-разрядным словом

В оперативном запоминающем устройстве 16-разрядного компьютера используется контроль целостности данных по чётности. Требуется описать возможную структуру ячейки памяти и её побитовое содержимое при хранении в машинном слове числа `756453₈`.

В источнике число названо «шестнадцатеричным», но индекс основания равен 8. Используйте восьмеричное основание и явно отметьте эту ошибку. Сначала установите, возможно ли хранение числа без потери информации в 16 разрядах; не отбрасывайте старшие разряды молча.

Для возможной структуры выберите 16 информационных битов и один отдельный бит чётности на всё слово (even parity: общее число единиц чётно). Контрольный бит не является дополнительным разрядом числа. Логический порядок записи — `[p | d15 … d0]`, от старших битов данных к младшим. Основной вопрос относится к точному хранению исходного числа; отдельно допустимо объяснить, что получится лишь при дополнительном, отсутствующем в источнике соглашении о взятии по модулю `2^16`.

Источник: `Test_20251109.md`, задание №1, вариант C.

---

# решение

Восьмеричная запись переводится в двоичную без ведущих нулей:

```text
7   5   6   4   5   3
111 101 110 100 101 011
```

Таким образом, `756453₈ = 253227₁₀ = 3DD2B₁₆`. Требуются 18 информационных битов: `111101110100101011`. Максимальное беззнаковое 16-разрядное число — `65535`, а `253227 > 65535`.

В исходной постановке точного побитового содержимого 16-разрядного слова с таким числом не существует. Структура из 16 битов данных и одного бита чётности имеет 17 физических битов, но только 16 из них информационные. Контрольный бит не устраняет противоречие. Даже замена контроля на один бит на байт не увеличила бы информационную ёмкость слова.

Если изменить разрядность данных, точное хранение потребует не менее 18 информационных битов; при одном бите чётности на это расширенное слово получится 19 физических битов. В исходных 18 битах 12 единиц, поэтому расширенная ячейка имела бы вид `0 | 111101110100101011`. Это уже не заданное 16-разрядное слово.

Только при дополнительном соглашении о сокращении по модулю `2^16` можно получить другой результат:

```text
253227 mod 65536 = 56619 = DD2B₁₆
d15…d0 = 1101 1101 0010 1011
p = 0, поскольку единиц 10
[p | d15…d0] = 0 | 1101 1101 0010 1011
```

При этом удаляются два старших бита `11`, то есть исходное число не сохраняется. Этот условный результат не является ответом о точном хранении `756453₈` в 16 битах.
