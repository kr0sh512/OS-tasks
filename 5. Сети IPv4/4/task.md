# Класс и сеть по восьмеричному IPv4-адресу

Дан 32-разрядный IPv4-адрес `23471543210` в восьмеричной системе счисления. Определите его исторический класс и номер сети в восьмеричном виде.

Источник: `Test_20251109.md`, задание №3, вариант A.

Исходная запись — единое 32-разрядное число, не последовательность восьмеричных октетов. Под сетью понимается базовая классовая сеть без дополнительного деления на подсети. Чтобы исключить неоднозначность слова «номер», укажите как старшую сетевую часть без хостовых битов, так и полный 32-разрядный адрес сети с нулевой хостовой частью.

---

# решение

Переведём число, сохраняя разбиение именно на восемь бит:

```text
23471543210₈ = 9CE6C688₁₆
             = 10011100 11100110 11000110 10001000₂
IPv4-адрес   = 156.230.198.136
```

Первый октет 156 принадлежит диапазону 128–191 и начинается с битов `10`. Это **класс B**, базовая маска `/16`, то есть `255.255.0.0`.

Полный адрес классовой сети:

```text
156.230.0.0 = 9CE60000₁₆ = 23471400000₈.
```

Если номер сети записывается как 16-разрядная старшая часть без 16 нулевых хостовых битов, то:

```text
9CE6₁₆ = 40166₁₀ = 116346₈.
```

Классифицирующие биты `10` здесь входят в старшие 16 бит. При соглашении, что под «номером» понимают только 14 переменных битов сети класса B без этих двух битов, получится `1CE6₁₆ = 16346₈`; это другая явно обозначенная запись того же classful-идентификатора, не другой адрес сети.

Нельзя просто приписать нулевые восьмеричные цифры к `116346`: граница 16 бит не кратна трём битам восьмеричного разряда.

**Ответ: класс B; полный 32-разрядный адрес сети 23471400000₈; старшая 16-разрядная сетевая часть 116346₈.**
