# МНСБ: число блоков массивов, вариант 1

В файловой системе свободные блоки учитываются с помощью массива номеров свободных блоков (МНСБ). Размер блока `N = 1024` байт, размер указателя `s = 4` байт. Всего в файловой системе `2^20 = 1048576` блоков. Сколько блоков занимают массивы МНСБ?

Восстановленная модель: каждый блок-голова МНСБ содержит `q = N / s` ячеек. В ячейке 0 хранится ссылка на следующую голову (`NULL` у последней), в остальных `q − 1` ячейках — номера свободных блоков; неиспользованные ячейки равны `NULL`. Каждая голова сама является свободным, учитываемым блоком: при выделении сначала выдаются номера из её ячеек, затем выдаётся сама голова и текущей становится следующая. Указатель на текущую голову хранится вне этих блоков. Массивы упакованы плотно, кроме, возможно, последнего.

Исходник сообщает общее число блоков ФС, а не число свободных. Для численного ответа дополнительно примите, что **все блоки свободны**, включая головы. Также укажите, как ответ зависит от неизвестного числа свободных блоков `F`, если это допущение снять. В рамках этой учебной модели отдельные занятые блоки суперблока и других метаданных из общего числа не вычитаются.

Источник: «Задачи.md», «Быстросчет свободных блоков», вариант 1.

---

# решение

Число блоков ФС: `T = 2^20 = 1048576`. В каждой голове `q = 1024 / 4 = 256` ячеек.

Одна полная группа учитывает `q − 1` свободных блоков через записи и ещё один свободный блок — саму голову, то есть всего `q` свободных блоков. Поэтому при `F > 0` число голов равно `H(F) = ceil(F / q)`; при `F = 0` голов нет и та же формула даёт ноль. Деление на `q − 1` было бы неверно: оно не учитывает возможность выдать саму голову.

При принятом допущении `F = T = 1048576`:

`H = ceil(1048576 / 256) = 4096` блоков.

Это число блоков, содержащих массивы МНСБ, а не число занятых блоков, исключённых из пула: головы входят в `F`. Если известно только общее число блоков `T`, но не свободное `F`, единственного численного ответа нет: он равен `ceil(F / 256)` при `0 ≤ F ≤ 1048576`. В частности, пустая ФС по свободному пулу даёт 0 голов, а полностью свободная — 4096.
