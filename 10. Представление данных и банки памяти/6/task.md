# Банк и смещение в видеопамяти объёмом 4 Мбайт

Видеопамять объёмом 4 Мбайт организована в 16 банков. Для адреса `735264₈` укажите номер банка и смещение в нём.

Используйте побайтную адресацию, `1 Мбайт = 2^20` байт и номера банков от 0 до 15. Способ расслоения в источнике не указан; для основного ответа явно примите низкоразрядное чередование (low-order interleaving): `bank = A mod 16`, `offset = floor(A / 16)`. Отличайте его от организации, в которой старшие биты выбирают один из непрерывных банков.

Источник: `Test_20251109.md`, задание №2, вариант C.

---

# решение

Общий объём памяти равен `4 · 2^20 = 2^22` байт; для адреса нужны 22 бита. Каждый из 16 равных банков содержит `2^22 / 16 = 2^18 = 262144` байта.

Перевод адреса:

```text
735264₈ = 111 011 101 010 110 100₂ = 244404₁₀
22-битная запись: 0000111011101010110100
```

При low-order чередовании четыре младших бита выбирают банк: `0100₂ = 4`. Оставшиеся 18 битов задают смещение:

```text
244404 = 16 · 15275 + 4
bank = 4
offset = 15275₁₀ = 3BAB₁₆
```

Адрес меньше `2^22`, а смещение меньше `2^18`, поэтому они укладываются в указанные объёмы.

Если вместо low-order принять high-order с 16 равными непрерывными областями по `2^18` байт, получится другая формула: `bank = floor(A / 2^18)`, `offset = A mod 2^18`. Для данного адреса это банк `0` и смещение `244404`. Следовательно, без явного выбора схемы исходное условие не определяет единственную пару; основной ответ выше относится к заявленному low-order.
