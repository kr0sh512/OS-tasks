# Преобразование адреса в восьмисегментной памяти

В компьютере используется восьмисегментная модель организации памяти. Виртуальные и физические адреса имеют размер `int` — **32 бита**. Все восемь сегментов процесса находятся в физической памяти.

Напишите функцию с точной сигнатурой:

```c
unsigned int VirtIntoPhys(segment *SegTable, unsigned int VirtAdr);
```

`VirtAdr` — виртуальный адрес; три старших бита задают номер сегмента, остальные 29 бит — смещение внутри него. `SegTable` указывает на массив из восьми описателей сегментов. Каждый описатель содержит размер сегмента в байтах и физический адрес его начала. Определите тип `segment` и прокомментируйте поля структуры.

Если смещение строго меньше размера сегмента, верните физический адрес соответствующего байта. Если смещение больше или равно размеру сегмента, завершите процесс **с кодом 25**. Ошибка не должна приводить к обычному возврату из функции.

Предполагается, что указатель и таблица корректны: каждый размер не превышает `2^29`, все сегменты помещаются в 32-битное физическое адресное пространство. Проверять корректность описателей не требуется. Это задача на функцию: стандартный ввод и формат печати результата не задаются.

Источник: «Задачи_вирт_память.docx», задача с сигнатурой `VirtIntoPhys` и кодом завершения 25.

---

# решение

Для восьми сегментов нужны три бита номера. Выделяем их сдвигом вправо на 29 бит; младшие биты оставляем маской `0x1fffffff`. Сравнение выполняется до сложения с физической базой. Граничный адрес с `offset == size` уже недопустим.

В исходном наброске вызов `exit(25)` оказался за закрывающей скобкой функции. Здесь он находится внутри ветви ошибки; при успешном преобразовании возвращается только допустимый физический адрес.

Код — самостоятельная единица трансляции C11 с требуемой функцией; `main` не нужен, поскольку функцию вызывает проверяющая программа. Требование о 32-битном `int` проверяется при компиляции, а не используется как вычисляемый во время исполнения размер адреса.

```c
#include <limits.h>
#include <stdlib.h>

_Static_assert(CHAR_BIT == 8 && sizeof(unsigned int) == 4 &&
               UINT_MAX == 0xffffffffU,
               "This task requires a 32-bit unsigned int");

typedef struct Seg {
    unsigned int size;    /* Размер сегмента в байтах. */
    unsigned int SegAdr;  /* Физический адрес начала сегмента. */
} segment;

unsigned int VirtIntoPhys(segment *SegTable, unsigned int VirtAdr)
{
    unsigned int SegNum = VirtAdr >> 29;
    unsigned int offset = VirtAdr & 0x1fffffffU;

    if (offset >= SegTable[SegNum].size) {
        exit(25);
    }
    return SegTable[SegNum].SegAdr + offset;
}
```
