# Предельное число виртуальных страниц

В 32-разрядном компьютере используется двухуровневая таблица страниц. Таблица первого уровня содержит 4096 записей, каждая таблица второго уровня — 1024 записи.

Какое максимальное число различных виртуальных страниц можно представить? Считайте, что все записи могут использоваться, а каждой записи второго уровня соответствует одна виртуальная страница. Требуется число виртуальных страниц, а не число различных физических кадров или объём физической памяти.

Источник: задание с пометкой «Колл-09.12.23» в документе «Задачи_вирт_память.docx».

---

# решение

Каждая из 4096 записей внешней таблицы выбирает таблицу второго уровня, в которой можно выбрать одну из 1024 страниц. Поэтому число представимых виртуальных страниц равно произведению размеров таблиц.

**Ответ: 4096 * 1024 = 2^12 * 2^10 = 2^22 = 4 194 304 страницы.**

На два индекса уходит 22 бита. При полном использовании 32-битного побайтного адресного пространства оставшиеся 10 бит задавали бы смещение, то есть размер страницы составлял бы 1024 байта; для ответа о числе страниц это дополнительное предположение не нужно.
