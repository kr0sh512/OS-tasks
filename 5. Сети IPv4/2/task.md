# Подсетевой каблучник

Иннокентий приехал к друзьям играть в Монополию и привёз подруге огромный хрупкий букет. Подняться с ним в квартиру он сможет только один раз: второй поездки в лифте букет не переживёт. Он хочет сделать сюрприз, поэтому должен заранее определить подъезд, этаж и квартиру, не звоня подруге.

Дому выделена сеть `76.111.116.0/22`, разделяемая между 14 подъездами. Хостовые номера в подсети подъезда соответствуют относительным номерам квартир в этом подъезде. В каждом подъезде 16 этажей: на первом две квартиры, на каждом из остальных — четыре.

Без учёта маски адрес квартиры подруги принадлежит историческому классу A, номер сети равен `114` в восьмеричной системе, номер хоста — `6F7665` в шестнадцатеричной системе.

Определите IPv4-адрес, маску подсети подъезда, подъезд, этаж и номер квартиры при общей нумерации дома. Этажи, подъезды и квартиры нумеруются с единицы.

Источник: `Задачи.md`, «Подсетевой каблучник».

Модельное соглашение, необходимое для однозначного ответа: каждому подъезду выделяют одну одинаковую минимальную по ёмкости обычную IPv4-подсеть; подсети, включая первую с нулевым смещением, назначают подъездам подряд по возрастанию адресов. Хостовые номера квартир начинаются с 1. Квартиры нумеруются по этажам снизу вверх, а общая нумерация продолжается в следующем подъезде. Эти правила распределения в исходнике полностью не определены; без них номера подъезда и общей квартиры неоднозначны.

---

# решение

В классе A номер сети занимает первый октет, а номер хоста — оставшиеся 24 бита:

```text
114₈ = 76₁₀
6F7665₁₆ = 6F.76.65₁₆ = 111.118.101₁₀
IPv4-адрес = 76.111.118.101
```

В одном подъезде `2 + 15 × 4 = 62` квартиры. Для обычной подсети нужны также адрес сети и широковещательный адрес: `62 + 2 = 64 = 2^6` адреса. Поэтому подъезд получает `/26`, маска **255.255.255.192**. В исходной `/22` имеется `2^(26−22) = 16` таких блоков, то есть 14 подъездов помещаются, а два блока остаются свободными.

Подсеть квартиры:

```text
76.111.118.101 AND 255.255.255.192 = 76.111.118.64
```

Её нулевой индекс среди блоков `/26` сети дома:

```text
((118 − 116) × 256 + 64) / 64 = 9.
```

Следовательно, при нумерации с единицы это **подъезд 10**. Его сеть — `76.111.118.64/26`, адреса квартир — `76.111.118.65`–`76.111.118.126`, широковещательный адрес — `76.111.118.127`.

Относительный номер квартиры равен `101 − 64 = 37`. Первые две квартиры находятся на первом этаже. Для остальных:

```text
этаж = 1 + ceil((37 − 2) / 4) = 10.
```

На десятом этаже находятся относительные квартиры 35–38. Номер квартиры во всём доме:

```text
(10 − 1) × 62 + 37 = 595.
```

**Ответ по оговорённой модели: подъезд 10, этаж 10, квартира 595; относительный номер 37.**

Без соглашения о порядке выдачи подсетей блок `76.111.118.64/26` можно назначить любому из 14 подъездов. Тогда при сохранении остальных правил этаж остаётся десятым, а общий номер квартиры принимает любое значение `62 × (p − 1) + 37`, где `p = 1, …, 14`. Произвольное распределение размеров подсетей или иной порядок квартир исходник также явно не исключает; основной ответ использует именно изложенную модель, а не выдаёт её за данное условие.
