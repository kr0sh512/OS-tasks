# Битовый массив: размер, вариант 3

Состояние блоков файловой системы описывается битовым массивом: на каждый блок ФС приходится ровно один бит. Файловая система содержит `2^30` блоков. Размер блока `N = 1024` байт. Сколько места занимает битовый массив в **байтах**?

Размер уже задан в блоках, поэтому перевод из единиц объёма не требуется. Массив описывает все блоки ФС, в том числе содержащие сам массив; эти блоки уже входят в указанный общий объём, а не прибавляются к нему. Считайте только сам битовый массив, без заголовков и других метаданных. Для хранения неполного байта нужен целый байт; при ответе в блоках неполный блок также округляется вверх.

Источник: «Задачи.md», «Битов много не бывает», вариант 3.

---

# решение

Число описываемых блоков: `B = 2^30 = 1073741824`.

На каждый из `B` блоков нужен один бит, поэтому длина массива в битах равна `1073741824`. В байтах:

`S = ceil(B / 8) = ceil(1073741824 / 8) = 134217728` байт.

Если размещать массив в блоках ФС, он занимает

`A = ceil(S / N) = ceil(134217728 / 1024) = 131072` блоков.

Оба округления в данном варианте точные, без остатка. Запрошенная величина: **134217728 байт**. Вычитать блоки самого массива из `B` нельзя: они тоже описываются битами и уже входят в размер ФС.
