# Размер таблицы второго уровня

В 32-разрядном компьютере используется страничная память с двухуровневой таблицей страниц. Память адресуется побайтно. Размер страницы — 4096 байт, внешняя таблица содержит 8192 записи.

Определите, сколько записей должна содержать каждая таблица второго уровня, чтобы можно было адресовать всё виртуальное адресное пространство. Разложите виртуальный адрес на поля. Под размером таблицы в этой задаче понимается число записей; размер одной записи в байтах не задан.

Источник: задание о таблице первого уровня из 8192 записей в документе «Задачи_вирт_память.docx».

---

# решение

Смещение занимает log2(4096) = 12 бит. Внешний индекс занимает log2(8192) = 13 бит. Внутреннему индексу остаётся 32 − 12 − 13 = 7 бит.

**Ответ: 2^7 = 128 записей в каждой таблице второго уровня.**

Проверка: `8192 * 128 * 4096 = 2^32` байт. В общем случае `L2 = 2^A / (P * L1)`.
