# Битовый массив: размер, вариант 1

Состояние блоков файловой системы описывается битовым массивом: на каждый блок ФС приходится ровно один бит. Объём файловой системы — `2 Тб`. Размер блока `N = 512` байт. Сколько места занимает битовый массив в **блоках ФС**?

В этом условии `Тб` трактуется как TiB: `1 TiB = 2^40` байт; это двоичная единица объёма, не терабиты. Массив описывает все блоки ФС, в том числе содержащие сам массив; эти блоки уже входят в указанный общий объём, а не прибавляются к нему. Считайте только сам битовый массив, без заголовков и других метаданных. Для хранения неполного байта нужен целый байт; при ответе в блоках неполный блок также округляется вверх.

Источник: «Задачи.md», «Битов много не бывает», вариант 1.

---

# решение

Число описываемых блоков: `B = 2 · 2^40 / 512 = 2^32 = 4294967296`.

На каждый из `B` блоков нужен один бит, поэтому длина массива в битах равна `4294967296`. В байтах:

`S = ceil(B / 8) = ceil(4294967296 / 8) = 536870912` байт.

Если размещать массив в блоках ФС, он занимает

`A = ceil(S / N) = ceil(536870912 / 512) = 1048576` блоков.

Оба округления в данном варианте точные, без остатка. Запрошенная величина: **1048576 блоков ФС**. Вычитать блоки самого массива из `B` нельзя: они тоже описываются битами и уже входят в размер ФС.
