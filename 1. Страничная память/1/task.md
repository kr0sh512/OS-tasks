# Размер внешней таблицы страниц: страница 2048 байт

В 32-разрядном компьютере используется двухуровневая таблица страниц. Память адресуется побайтно, размер страницы — 2048 байт. Каждая таблица второго уровня содержит 1024 записи.

Определите число записей во внешней таблице (таблице первого уровня), необходимое для адресации всего 32-разрядного виртуального пространства. Объясните распределение битов адреса между двумя индексами и смещением. Размер записи таблицы в байтах вычислять не требуется.

Источник: первое задание документа «Задачи_вирт_память.docx».

---

# решение

2048 = 2^11, поэтому смещение занимает 11 бит. Внутренний индекс занимает log2(1024) = 10 бит. Для внешнего индекса остаётся 32 − 11 − 10 = 11 бит.

**Ответ: 2^11 = 2048 записей.**

Общая формула: `L1 = 2^A / (P * L2)`, где A — разрядность адреса, P — размер страницы, L2 — число записей таблицы второго уровня. Это число записей, а не размер таблицы в байтах.
