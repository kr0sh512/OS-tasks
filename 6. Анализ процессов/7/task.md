# Классика жизни

Источник: `Задачи.md`, «Классика жизни».

Начальный процесс X создаёт сыновей Y и Z, а Y создаёт W. Первый `fork` обязательно создаёт Y:

```text
X
├── Y
│   └── W
└── Z
```

Найдите количество различных полных выводов и укажите отдельно вывод каждого процесса. Приведите точное описание множества всех порядков строк. Стандартные заголовки подразумеваются. `fork` успешен, вывод атомарен и небуферизован. Вызов `waitpid` с WNOHANG не обязан дождаться ребёнка; при отсутствии детей он закономерно возвращает −1/ECHILD. Буквальная гарантия источника «все системные вызовы успешны» в этой точке невыполнима; иных ошибок нет.

```c
int main(void) { // X
    int status;
    int pid = getpid();
    if (fork() == 0) { // Y
        printf("%d, %d\n", pid, getpid());
        pid = getpid();
    }
    fork();
    printf("%d, %d\n", pid, getpid());
    waitpid(-1, &status, WNOHANG);
    return 0;
}
```

---
# решение

Всего 40 выводов.

```text
Процесс X печатает:
X, X

Процесс Y печатает:
X, Y
Y, Y

Процесс Z печатает:
X, Z

Процесс W печатает:
Y, W
```

Полное множество — все перестановки этих пяти различных строк, в которых `X, Y` стоит раньше обеих строк `Y, Y` и `Y, W`. Иных ограничений нет. Среди трёх названных строк первая обязана быть `X, Y`, поэтому число перестановок равно 5!/3 = 40.

До первого `fork` переменная pid равна X. В Y первая печать ещё использует X, затем pid меняется на Y. Второй `fork` копирует X в Z и Y в W. Y создаёт W только после своей первой печати; X и Z могут печатать независимо от этой ветви. `waitpid` находится после печати и не добавляет ограничений на строки, а WNOHANG вообще не блокирует ожидание завершения. Переподчинение не влияет на ответ, поскольку `getppid` не вызывается. У листьев `waitpid` даёт ECHILD, а не успешный PID.
