# Два fork с логическим И

Источник: `Test_20251109.md`, задание №4, вариант А.

Дана иерархия:

```text
A
├── B
│   └── C
└── D
```

Создаваемые дети получают PID согласно дереву и порядку братьев в списке. В самом варианте начальный PID не подписан: установите все совместимые старты, затем перечислите все возможные выводы. Не требуется создавать каждую вершину схемы. Каждый `fork` успешен, `printf` атомарен и небуферизован; заголовки подразумеваются.

```c
int main() {
    if (fork() && fork()) {
        printf("X %d\n", getpid());
    } else {
        printf("Y %d\n", getpid());
    }
    return 0;
}
```

---
# решение

Единственный совместимый начальный процесс — A: программа создаёт ровно двух его непосредственных детей, B и D. У B в схеме лишь один ребёнок, у C и D нет детей. C не создаётся.

Всего 6 выводов:

```text
X A
Y B
Y D
```
```text
X A
Y D
Y B
```
```text
Y B
X A
Y D
```
```text
Y B
Y D
X A
```
```text
Y D
X A
Y B
```
```text
Y D
Y B
X A
```

`&&` вычисляется слева направо с коротким замыканием. В первом ребёнке B первый `fork` вернул 0: второй `fork` не вызывается и печатается Y B. В A первый результат положителен, поэтому выполняется второй `fork`. Его ребёнок D получает 0 и печатает Y D. Только A получает два ненулевых результата и печатает X A. Ограничений между тремя строками нет: 3!=6. Нельзя подменять `&&` запятой или побитовым `&`, которые дали бы другую структуру процессов.
