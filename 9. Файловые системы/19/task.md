# Больше блоков богу блоков

Источник: `Задачи на код.md`, «Больше блоков богу блоков».

В файловой системе для описания файла используется массив номеров блоков файла — МАБФ классического размера. Размер номера — `unsigned`, размер блока файловой системы равен внешнему макросу `N`. Массив доступен через `unsigned *mabf`. Функция

```c
unsigned *give_block(unsigned num);
```

возвращает указатель на блок с указанным номером либо `NULL` при ошибке доступа. Номер `0` означает конец массива и блоком не считается.

Напишите функцию

```c
long long file_block_size(unsigned *mabf);
```

Она должна вернуть размер файла в блоках данных. При ошибке доступа требуется вернуть внешний код `EINVALID`.

Термин «классического размера» и правила завершения обхода в исходнике недостаточно конкретны. Здесь явно принимаются следующие соглашения:

1. МАБФ содержит ровно 13 записей: `mabf[0..9]` — десять прямых номеров блоков данных; `mabf[10]` — номер блока одинарной косвенности; `mabf[11]` — двойной; `mabf[12]` — тройной. Макроса иной длины МАБФ нет.
2. Косвенный блок содержит `q = N / sizeof(unsigned)` записей, `q >= 1`. Возможный остаток байтов блока не используется. При одинарной косвенности записи указывают на данные; при двойной — на блоки одинарной; при тройной — на блоки двойной.
3. Каждый массив плотный: сначала идут значимые ненулевые записи, затем, если осталось место, нули. Первый ноль завершает именно этот массив. В МАБФ это прекращает обработку всех последующих его записей; в косвенном блоке — всех последующих записей этого блока. «Дырок» с данными после нуля нет. Полностью заполненному массиву завершающий ноль не нужен.
4. Структура представляет корректное дерево без повторного использования одного блока в разных местах; размер данных допустимого файла помещается в `long long`. `EINVALID` — отрицательная константа, представимая этим типом. `mabf`, если не равен `NULL`, доступен для чтения всех 13 записей; `mabf == NULL` считается ошибкой доступа.
5. Успешный `give_block` возвращает доступный для чтения массив минимум из `q` номеров, сохраняющийся при следующих вызовах; неуспешный возвращает `NULL`. Номера блоков данных не нужно разыменовывать: функция считает блоки, а не читает содержимое файла. Ошибки чтения самих данных потому не обнаруживаются и для подсчёта не требуются.

Не нужно считать сами блоки косвенности и нельзя вызывать `give_block(0)`.

---
# решение

Одинарный косвенный блок прибавляет по одному блоку данных за каждую запись до первого нуля. Для двойной и тройной косвенности ту же операцию повторяем на следующем уровне. При `NULL` немедленно возвращаем ошибку, не выдавая частичный размер. Глубина рекурсии ограничена тремя уровнями и не зависит от размера файла.

```c
#include <stddef.h>

/* N и отрицательная константа EINVALID заданы извне. */
unsigned *give_block(unsigned num);

/* num != 0; level лежит в диапазоне от 1 до 3. */
static long long mabf_count_indirect(unsigned num, unsigned level)
{
    unsigned *block = give_block(num);
    if (block == NULL)
        return EINVALID;

    const size_t q = N / sizeof(unsigned);
    long long count = 0;
    for (size_t i = 0; i < q; ++i) {
        unsigned child = block[i];
        if (child == 0)
            break;
        if (level == 1) {
            ++count;
        } else {
            long long part = mabf_count_indirect(child, level - 1);
            if (part == EINVALID)
                return EINVALID;
            count += part;
        }
    }
    return count;
}

long long file_block_size(unsigned *mabf)
{
    if (mabf == NULL)
        return EINVALID;

    long long count = 0;
    for (size_t i = 0; i < 13; ++i) {
        unsigned num = mabf[i];
        if (num == 0)
            break;
        if (i < 10) {
            ++count;
        } else {
            unsigned level = (unsigned)(i - 9);
            long long part = mabf_count_indirect(num, level);
            if (part == EINVALID)
                return EINVALID;
            count += part;
        }
    }
    return count;
}
```

На каждой глубине сначала проверяется результат `give_block`; этот общий обработчик покрывает ошибку корня одинарной, двойной или тройной косвенности, а также любого внутреннего косвенного блока. Чтения по `NULL` и вызова с нулевым номером нет. Прямые номера и последние ненулевые записи одинарных блоков считаются без обращения к содержимому данных. Индукцией по уровню косвенности получается ровно число достижимых листьев, то есть блоков данных.

Максимальный размер равен `10 + q + q² + q³` блокам данных; индексные блоки в эту формулу не включаются. Для конкретного файла время пропорционально числу просмотренных записей, плюс не более одного завершающего нуля на прочитанный массив. Дополнительная память `O(1)`, поскольку глубина не превосходит трёх; динамического выделения нет.

Для описания конкретных аргументов используется текстовая запись: строка `q число`, строка `mabf` и 13 номеров, строка `blocks количество`, затем по строке на каждый индексный блок `номер: q_значений` либо `номер: ERROR`. Полагается `N = q * sizeof(unsigned)`; `give_block` возвращает указанное содержимое или `NULL` для `ERROR` и для отсутствующего номера. Блоки данных в этом отображении не нужны. Результат — единственное число либо символическое имя внешнего кода `EINVALID`. Это описание массива и поведения предоставленной функции `give_block`, а не требование написать дополнительный текстовый интерфейс.
