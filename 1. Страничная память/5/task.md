# Прямая таблица страниц: адресация машинных слов

Дан 32-разрядный компьютер со страничной организацией памяти. Размер страницы — **512 машинных слов**, минимальная адресуемая единица памяти — **машинное слово**, а `unsigned` занимает 32 бита и соответствует одному машинному слову. Виртуальные и физические адреса — 32-разрядные номера слов, а не байтов.

Опишите на Си функцию с прототипом:

```c
unsigned To_PA(unsigned *Page_Tab, unsigned Virt_A, int PID);
```

`Page_Tab` — прямая таблица страниц текущего процесса, `Virt_A` — виртуальный адрес, `PID` — идентификатор другого, контролирующего процесса. Если страница находится в памяти, функция возвращает соответствующий физический адрес. Иначе она отправляет контролирующему процессу сигнал `SIGPL`, после чего завершает свой процесс вызовом `exit(No_Page)`. `SIGPL` и `No_Page` — константы, заданные вне функции; `SIGPL` обозначает допустимый сигнал POSIX, а `No_Page` — пользовательский код завершения.

В решении необходимо описать структуру таблицы и интерпретацию каждой записи. Таблица содержит `2^23` записей, по одной на каждую виртуальную страницу; вызывающая сторона предоставляет корректный массив такого размера.

Принятое представление из исходного решения: биты 31–9 записи содержат 23-разрядный номер физической страницы, биты 8–1 зарезервированы, бит 0 — признак присутствия (`1` — страница в памяти, `0` — отсутствует). Зарезервированные биты при преобразовании игнорируются.

Источник: документ «Задачи_вирт_память», условие и набросок решения функции `To_PA`. Ошибку приоритета операторов в проверке присутствия необходимо исправить.

---

# решение

Поскольку `512 = 2^9`, младшие 9 бит адреса — смещение внутри страницы, старшие 23 — индекс в прямой таблице. Номер физической страницы извлекается сдвигом записи вправо на 9. После проверки присутствия он объединяется с исходным смещением.

Ни умножение на размер слова в байтах, ни сдвиг на 11 здесь не нужны: адресация по условию словная. Выражение `el & 1 == 0` неверно: оно разбирается как `el & (1 == 0)`, то есть всегда даёт ноль.

Код — самостоятельная единица трансляции для C11/POSIX. Внешний код должен определить объекты `const int SIGPL` и `const int No_Page` (например, со значениями `SIGUSR1` и `1`); они объявлены ниже, но не переопределены внутри функции. `PID` должен быть положительным идентификатором контролирующего процесса, отличного от вызывающего. Даже если отправка сигнала завершится ошибкой, после попытки отправки выполняется требуемый `exit`.

```c
#define _POSIX_C_SOURCE 200809L
#include <limits.h>
#include <signal.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>

_Static_assert(UINT_MAX == 0xffffffffU, "unsigned must be 32-bit");

extern const int SIGPL;
extern const int No_Page;

unsigned To_PA(unsigned *Page_Tab, unsigned Virt_A, int PID)
{
    unsigned offset = Virt_A & 0x1ffU;
    unsigned vp = Virt_A >> 9;
    unsigned entry = Page_Tab[vp];

    if ((entry & 1U) == 0U) {
        (void)kill((pid_t)PID, SIGPL);
        exit(No_Page);
    }

    unsigned pp = entry >> 9;
    return (pp << 9) | offset;
}
```

Доступ к таблице и преобразование занимают `O(1)` времени и `O(1)` дополнительной памяти. Самой прямой таблице требуется `2^23` машинных слов.
