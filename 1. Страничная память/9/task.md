# Двухуровневая таблица: 2048 и 512 записей

В компьютере с 32-разрядными виртуальными и физическими адресами типа `unsigned` используется двухуровневая таблица страниц. Таблица первого уровня содержит **2048 записей**, каждая таблица второго уровня — **512 записей**.

Напишите на Си функцию:

```c
unsigned To_PA_TwoLevel(unsigned VA, record *const *table);
```

Таблица первого уровня — массив указателей на таблицы второго уровня. Нулевой указатель означает, что соответствующей таблицы второго уровня нет. Ненулевой указатель адресует массив из 512 записей типа `record`. Каждая запись содержит номер физической страницы `unsigned PP` и признак присутствия `unsigned valid`: `1` — страница присутствует, `0` — отсутствует. Номер физической страницы хранится как число в младших 20 битах `PP`, остальные биты равны нулю.

Функция возвращает физический адрес при успешном переводе. При отсутствии таблицы второго уровня она должна вызвать `exit(No_Table)`, а при существующей таблице, но отсутствующей странице — `exit(No_Page)`. Это **разные причины ошибки и разные коды завершения**. Сигналы посылать не нужно.

Источник: фотография доски `photo_2026-11-18_21-12-22.jpg`. Полного текста условия на снимке нет. Восстановленные соглашения: адресуется байт, все 32 бита виртуального адреса распределяются между двумя индексами и смещением, размер страницы отсюда равен 4096 байтам; `No_Table = 1`, `No_Page = 2`, имя функции и точный тип параметров зафиксированы выше. Вызывающая сторона передаёт ненулевой массив первого уровня длиной 2048; все его ненулевые указатели и присутствующие записи корректны. Размер указателей среды, на которой запускается модель, не обязан быть 32 бита: они представляют связи между таблицами модели, а не физические адреса моделируемой машины.

---

# решение

На индекс первого уровня нужно `log2(2048) = 11` бит, второго — `log2(512) = 9` бит. На смещение остаётся `32 - 11 - 9 = 12` бит, то есть страница содержит `2^12 = 4096` байтов.

Разбиение адреса:

- биты 31–21: `VP1 = VA >> 21`;
- биты 20–12: `VP2 = (VA >> 12) & 0x1ffU`;
- биты 11–0: `offset = VA & 0xfffU`.

Сначала проверяем `table[VP1]`: пока указатель нулевой, читать запись второго уровня нельзя. Затем проверяем `valid` выбранной записи. Только после обеих проверок строим физический адрес `(PP << 12) | offset`.

В наброске использовано сложение без необходимых скобок вокруг сдвига. В C сложение имеет больший приоритет, чем сдвиг: выражение `offset + PP << 12` сдвинуло бы и само смещение. Здесь используется явное объединение непересекающихся полей. Нельзя также возвращать код ошибки как физический адрес: обработка ошибки по условию завершает процесс.

Код ниже — самостоятельная единица трансляции C11. Все типы и коды ошибок объявлены в ней; внешние определения констант не требуются.

```c
#include <limits.h>
#include <stdlib.h>

_Static_assert(UINT_MAX == 0xffffffffU, "unsigned must be 32-bit");

enum {
    LEVEL1_COUNT = 2048,
    LEVEL2_COUNT = 512,
    No_Table = 1,
    No_Page = 2
};

typedef struct record {
    unsigned PP;
    unsigned valid;
} record;

unsigned To_PA_TwoLevel(unsigned VA, record *const *table)
{
    unsigned vp1 = VA >> 21;
    unsigned vp2 = (VA >> 12) & 0x1ffU;
    unsigned offset = VA & 0xfffU;
    const record *level2 = table[vp1];

    if (level2 == NULL) {
        exit(No_Table);
    }
    if (level2[vp2].valid == 0U) {
        exit(No_Page);
    }

    return (level2[vp2].PP << 12) | offset;
}
```

Время перевода — `O(1)`, дополнительная память функции — `O(1)`. Таблицы второго уровня можно создавать лишь для используемых областей виртуального адресного пространства; отсутствие такой таблицы не тождественно отсутствию одной страницы в уже существующей таблице.
