# Класс C и максимальные номера хостов

Даны IPv4-адрес `201.34.155.200` и маска `255.255.255.224`. Определите:

1. Базовый исторический класс сети.
2. Адрес сети с указанной маской.
3. Максимальные номера хостов в базовой классовой сети и в подсети с указанной маской, а также их разность.

Источник: `Test_20251109.md`, задание №3, вариант C.

Различайте максимальное значение хостовой битовой части и количество доступных адресов устройств. Для обычных сетей адрес сети и широковещательный адрес не назначаются рабочим станциям. Приведите обе величины, не подменяя одну другой.

---

# решение

Первый октет 201 лежит в диапазоне 192–223, его старшие биты — `110`. Базовый класс — **C**, классовая маска `/24`, сеть `201.34.155.0/24`.

Последний октет заданной маски:

```text
224 = 11100000₂.
```

Следовательно, маска равна `/27`; хостовая часть занимает пять бит. Побитовое И последних октетов:

```text
200 = 11001000₂
224 = 11100000₂
192 = 11000000₂
```

Искомый адрес сети — **201.34.155.192/27**. Диапазон всех адресов подсети: `201.34.155.192`–`201.34.155.223`; широковещательный адрес — `201.34.155.223`, устройства могут использовать `.193`–`.222`. Хостовый номер данного адреса в подсети равен `200 − 192 = 8`.

Максимальное значение хостовой битовой части:

```text
класс C, /24: 2^8 − 1 = 255;
подсеть /27:  2^5 − 1 = 31;
разность:     255 − 31 = 224.
```

Эти максимальные номера соответствуют широковещательным адресам и не назначаются устройствам. Числа назначаемых адресов равны соответственно `2^8 − 2 = 254` и `2^5 − 2 = 30`; их разность также 224, но совпадение разностей не означает равенства исходных понятий. Максимальные назначаемые хостовые номера — 254 и 30 соответственно, поскольку номер 0 тоже зарезервирован.

**Ответ: класс C; сеть 201.34.155.192/27; максимальные хостовые номера 255 и 31, разность 224; доступных адресов устройств 254 и 30.**
