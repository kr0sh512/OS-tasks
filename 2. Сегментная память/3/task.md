# Шестнадцать сегментов и ошибка Invalid_Segment

В 32-разрядной машине используется сегментная организация памяти с **16 сегментами**. Виртуальный адрес состоит из номера сегмента в четырёх старших битах и смещения в младших 28 битах. Физический адрес также имеет размер 32 бита; память адресуется побайтно.

Напишите функцию преобразования виртуального адреса в физический и определите структуру описателя сегмента. Таблица содержит 16 описателей; у каждого есть физический адрес начала `base` и размер `size` в байтах. Если `offset < size`, результат равен `base + offset`. Иначе нужно завершить процесс вызовом `exit(Invalid_Segment)`; недопустимое смещение не должно давать возвращаемого физического адреса.

**Восстановленные соглашения:** на фотографии приведён набросок решения, а не полное текстовое условие. Здесь приняты сигнатура `uint32_t VAtoPA(const record table[16], uint32_t VA)` и тип `record` с полями `base`, `size`. Числовое значение `Invalid_Segment` на доске не определено: в этом варианте оно равно **1**. Для 16 сегментов однозначно получаются сдвиг **28** и маска **`0x0fffffff`**, независимо от нечётких записей констант на снимке. Все сегменты считаются размещёнными в физической памяти; переданная таблица корректна, каждый размер не больше `2^28`, а каждый сегмент целиком помещается в 32-битное физическое адресное пространство.

Это задача на функцию: стандартный ввод и формат вывода не задаются.

Источник: фотография доски 21-12-19, схема «32 bit, 16 segments» и набросок с `Invalid_Segment`.

---

# решение

`16 = 2^4`, поэтому номер сегмента занимает четыре бита, а смещение — `32 - 4 = 28` бит. Выражение `VA >> 28` даёт индекс от 0 до 15; маска `0x0fffffff` оставляет только смещение. Проверяем строгую границу сегмента, а затем прибавляем физическую базу.

Код — единица трансляции C11, предоставляющая функцию для вызывающей программы. Тип `uint32_t` фиксирует ширину адресов. Значение `Invalid_Segment` явно определено, а не взято из неопределённой константы на доске.

```c
#include <stdint.h>
#include <stdlib.h>

enum { Invalid_Segment = 1 };

typedef struct record {
    uint32_t base;  /* Физический адрес первого байта сегмента. */
    uint32_t size;  /* Размер сегмента в байтах. */
} record;

uint32_t VAtoPA(const record table[16], uint32_t VA)
{
    uint32_t number = VA >> 28;
    uint32_t offset = VA & UINT32_C(0x0fffffff);

    if (offset >= table[number].size) {
        exit(Invalid_Segment);
    }
    return table[number].base + offset;
}
```
