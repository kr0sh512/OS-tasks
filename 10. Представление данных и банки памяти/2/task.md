# Контроль чётности 32-разрядного слова с восьмеричным числом

В оперативном запоминающем устройстве 32-разрядного компьютера используется контроль целостности данных по чётности. Опишите возможную структуру ячейки памяти и её побитовое содержимое при хранении в машинном слове числа `37564012743₈`. Проверьте, помещается ли число в слово.

В источнике число ошибочно названо «шестнадцатеричным», хотя индекс основания равен 8. Здесь основание определяется по индексу: число восьмеричное.

Выберите один отдельный контрольный бит на всё 32-разрядное слово и чётное число единиц (even parity). Контрольный бит не входит в разряды данных. Записывайте содержимое в порядке `[p | d31 … d0]` от старших разрядов данных к младшим; порядок байтов в памяти не задаётся.

Источник: `Test_20251109.md`, задание №1, вариант B.

---

# решение

Одна возможная структура — 32 информационных бита и один бит чётности: 33 физических бита. Схема с отдельным битом чётности на каждый байт также возможна, но здесь не выбрана.

При переводе восьмеричных цифр в тройки битов получаем:

```text
3   7   5   6   4   0   1   2   7   4   3
011 111 101 110 100 000 001 010 111 100 011
```

Здесь 33 записанных бита, но первый из них — ведущий нуль. Поэтому требуются ровно 32 значащих бита; отбрасывание этого нуля не меняет число:

```text
1111 1101 1101 0000 0001 0101 1110 0011
```

`37564012743₈ = FDD015E3₁₆ = 4258272739₁₀ < 2^32 = 4294967296`. Число помещается в беззнаковое 32-разрядное слово; трактовка как положительного знакового 32-разрядного целого здесь не требуется.

В данных 18 единиц. Для чётного общего количества нужен `p = 0`.

```text
0 | 1111 1101 1101 0000 0001 0101 1110 0011
```
