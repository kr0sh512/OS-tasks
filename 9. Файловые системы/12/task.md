# Связное размещение: число обменов, вариант 4

Файл хранится в файловой системе со связным размещением блоков. Требуется прочитать байты из диапазона `D = {(1234, 5678), [7800, 9600]}`. Размер блока `N = 128` байт, размер ссылки на следующий блок файла `M = 1` байт. Нумерация байтов файла начинается с `K = 0`. Определите минимальное число обменов для получения запрошенных данных.

Соглашения модели: один обмен читает один блок ФС целиком; ссылка занимает `M` байт внутри блока, поэтому полезные данные занимают `N − M` байт. Номер первого блока файла уже известен, но его содержимое и все последующие блоки отсутствуют в кэше. Индекса для произвольного перехода нет: номер следующего блока узнаётся только из прочитанного предыдущего. Расходы на поиск самого файла не учитываются. Файл достаточно длинный, все чтения успешны, а границы диапазонов относятся к целым номерам байтов файла. При нескольких диапазонах разрешён один общий проход с сохранением уже прочитанного.

Источник: «Задачи.md», «Быстросчет обменов», вариант 4.

---

# решение

Полезная ёмкость блока `P = N − M = 128 − 1 = 127` байт. Блок с индексом `j`, считая с нуля, содержит номера байтов от `K + jP` до `K + (j + 1)P − 1`.

Первый интервал задаёт номера от 1235 до 5677 включительно; второй — от 7800 до 9600 включительно. Последний нужный байт имеет номер 9600. Это объединение двух запросов, а не два независимых чтения с обязательным возвратом к началу.

Индекс последнего нужного блока:

`j_last = floor((b_last − K) / P) = floor((9600 − 0) / 127) = 75`.

Чтобы получить ссылку на этот блок, требуется последовательно прочитать все блоки от нулевого до него включительно. Поэтому

`E = j_last + 1 = 76` обменов.

Первый нужный байт находится в блоке с индексом `floor((1235 − 0) / 127) = 9`, но вычитать этот индекс из числа обменов нельзя: предыдущие блоки всё равно читаются ради ссылок. Один последовательный проход достигает указанной нижней границы, значит ответ минимален.

Для первого диапазона последний нужный блок имеет индекс `floor(5677 / 127) = 44`, для второго первый — `floor(7800 / 127) = 61`, а последний — 75. Блоки с индексами 45..60 не содержат запрошенных байтов, но их необходимо прочитать ради продвижения по цепочке. Уже пройденные блоки повторно читать не требуется; общий проход до индекса 75 требует 76 обменов.
