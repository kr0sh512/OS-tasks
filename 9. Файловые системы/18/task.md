# МНСБ — Мне надо следить за блоками

Источник: `Задачи на код.md`, «МНСБ — Мне надо следить за блоками».

В системе свободные блоки выдаются с помощью связанных массивов указателей. Размер блока равен внешнему макросу `N`, размер одной записи — `sizeof(void *)`; следовательно, в блоке помещается `q = N / sizeof(void *)` записей. Указатель на текущий массив в суперблоке имеет тип `void **mnsb`.

Напишите функцию

```c
void *give_free_block(void ***mnsb_superblock_place);
```

Она должна выдать один свободный блок либо вернуть `NULL`, если свободных блоков нет. Если адрес можно получить из текущего блока без перехода к следующему, нужно выбрать его. Указатель в суперблоке должен оставаться валидным после каждого вызова.

Исходник не задаёт расположение связи между массивами и судьбу блока, хранящего сам массив. Для однозначности принимается следующая полная модель:

- `q >= 2`. Блоки имеют достаточный размер и выравнивание для массива `void *`; записи изначально содержат корректные значения указателей, а не произвольные байты.
- `mnsb_superblock_place` — валидный адрес поля суперблока. Значение `*mnsb_superblock_place` равно адресу текущего блока-головы либо `NULL`, когда список пуст. `NULL` — допустимое состояние этого поля, а не испорченный указатель.
- Каждый блок-голова сам является свободным блоком, временно занятым хранением списка. В его ячейке `0` хранится адрес следующего блока-головы либо `NULL`; ячейки `1..q-1` хранят адреса остальных свободных блоков. Неиспользованные ячейки равны `NULL`; между занятыми ячейками могут быть пропуски.
- Цепочка голов конечна и не имеет циклов. Все головы и все ненулевые указатели полезных ячеек обозначают разные блоки; нет повторений внутри списка и пересечений между головами и полезными ячейками.
- Сначала выдаётся первая по индексу ненулевая ячейка `1..q-1` текущей головы. Если таких ячеек нет, следующая голова сохраняется в поле суперблока, а прежняя голова выдаётся как свободный блок. Сам переход не должен поглощать или терять блок старой головы.

Нельзя выделять или освобождать память, читать следующую голову ради выбора блока либо рекурсивно обходить список. Разрешается только прочитать адрес следующей головы из ячейки `0`, когда текущая голова исчерпана.

---
# решение

```c
#include <stddef.h>

/* N задан извне; N / sizeof(void *) >= 2. */
void *give_free_block(void ***mnsb_superblock_place)
{
    void **head = *mnsb_superblock_place;
    if (head == NULL)
        return NULL;

    const size_t q = N / sizeof(void *);
    for (size_t i = 1; i < q; ++i) {
        if (head[i] != NULL) {
            void *result = head[i];
            head[i] = NULL;
            return result;
        }
    }

    void **next = (void **)head[0];
    *mnsb_superblock_place = next;
    return head;
}
```

Пока у головы есть полезная запись, поле суперблока не меняется. После выдачи записи она обнуляется, поэтому повторно выдана не будет. Если записей больше нет, мы сначала сохраняем связь и обновляем суперблок, затем передаём старую голову вызывающему коду. После этого вызывающий вправе перезаписать весь выданный блок: ни суперблок, ни дальнейшая работа функции от старой головы больше не зависят. Для последней головы связь равна `NULL`, и следующий вызов корректно вернёт `NULL`.

Каждый вызов просматривает не более `q-1` локальных ячеек, требует `O(q)` времени и `O(1)` дополнительной памяти, не разыменовывает следующую голову и не теряет ни одного блока. Суммарное множество свободных блоков уменьшается ровно на возвращённый ненулевой адрес.

Для описания конкретных аргументов используются символические имена реально различных адресов: строка `q число`, строка `head имя_или_NULL`, строка `heads количество`, затем по строке на каждый блок-голову: `имя slot0 slot1 ... slot(q-1)`. Другие имена обозначают обычные свободные блоки без используемого содержимого. Завершает описание строка `calls количество`. Полагается `N = q * sizeof(void *)`; между вызовами выданные блоки не изменяются и не возвращаются в список. Результат содержит по строке `номер return=имя_или_NULL head=имя_или_NULL` после каждого вызова. Это представление адресов и последовательности вызовов данной функции, а не отдельная программа с текстовым интерфейсом.
