# База индукции

Источник: `Задачи.md`, «База индукции».

Начальный процесс P1 выполняет программу. Первый `fork` создаёт P2, второй — P3:

```text
P1
├── P2
└── P3
```

Перечислите все возможные выводы, включая изменение родителя после завершения P1. Считайте каждый вызов `printf` атомарным и небуферизованным: одна строка не перемешивается с другой. Аргументы вычисляются до печати; между чтением PID родителя и самой печатью процесс может быть вытеснен. Все `fork` успешны. PID обозначены символами, а не конкретными числами. `R` — PID фактического усыновителя осиротевшего процесса (не обязательно 1); после усыновления он остаётся жив. Чужие процессы не создают и не завершают детей рассматриваемых процессов. Заголовки стандартных библиотек подразумеваются.

```c
int main(int argc, char **argv) {
    if (fork() == 0) {
        printf("%d %d \n", getppid(), getpid());
        exit(0);
    }
    if (fork() == 0) {
        printf("%d \n", getpid());
        exit(0);
    }
    return 0;
}
```

---
# решение

Всего 4 различных вывода (пробелы в конце строк несущественны):

```text
P1 P2
P3
```
```text
P3
P1 P2
```
```text
R P2
P3
```
```text
P3
R P2
```

P2 печатает один раз, P3 — один раз, P1 не печатает. P1 не ждёт детей и может завершиться раньше чтения `getppid()` в P2. Если P2 уже прочитал P1, последующее завершение P1 не меняет сохранённый аргумент. Оба порядка строк возможны для обоих значений родителя.
